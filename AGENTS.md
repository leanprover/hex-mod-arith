# Released Hex mirror

This repository is a published mirror of `leanprover/hex-dev`. Develop source,
README, SPEC, benchmark, and conformance changes in `hex-dev`; the release sync
regenerates the managed paths here and rewrites all Hex revision pins together.
Do not hand-edit managed files in this repository.

Computational repositories are Mathlib-free. Repositories ending in `-mathlib`
contain correspondence proofs and Mathlib-facing APIs.
